## 1. Must-Delete (Lens 1 — YAGNI)

**Nominated highest-leverage scope-safe cut: fold subtask `3.2` ("Update skill templates for provider-neutral path language") into `3.1`.**

- **Location:** `docs/tasks/main/specs/tasks.json` subtask `3.2`; `templates/skills/self-update/SKILL.md:27`,`:80`; `templates/skills/nightly-consolidation/SKILL.md:74`; renderer at `scripts/agent.mjs:423` (`universalSkillValues`), `:439` (`skills_dir`).
- **Rationale:** The agreed scope requires only that Academy universal skills are *available* to Codex via `.agents/skills` (`scope.md:38`, `scope.md:73`) — that is delivered entirely by `3.1`'s per-surface rendering. `3.2` exists solely to reword human-readable template prose (e.g. the literal label `.claude/skills` next to the already-correct `{{skills_dir}}` variable). Once `3.1` parameterizes `universalSkillValues` per target surface, `{{skills_dir}}` resolves to the right absolute path for each surface; the remaining wording change is cosmetic and behaviorally inert for Codex. Carrying it as its own tracked subtask with its own predecessor edge and an unverifiable `type:"observable"` "without implying Codex is unsupported" criterion (see L1-adjacent) adds planning overhead disproportionate to a label edit. Merging the one mechanical assertion ("rendered `.agents/skills` files contain no hardcoded `.claude/skills` label") into `3.1` removes a subtask without cutting any agreed scope item.
- **Note:** This is a mechanism/structure simplification, not a scope cut. If review prefers to keep `3.2`, the minimum fix is to drop its second `type:"observable"` criterion and make the surviving assertion the path-correctness check moved up into `3.1` (see M1). The next-best alternative cut is collapsing Phase-0 stubs `1.1`/`1.2`/`1.4`/`1.5` into one "write pending RED tests" subtask (keep `1.3` separate for its real-Codex gate).
